OPEN IN SPCK ON YOUR PHONE:
1. Download the ZIP and extract it using your phone's Files app.
2. Open/import the extracted folder as a project in Spck.
3. Open index.html and tap Preview.
4. Test the page links and contact form.

PUBLISH ON GITHUB PAGES:
1. Upload all five HTML pages plus style.css and script.js to the root of your GitHub repository.
2. Upload the entire images folder, including both PNG files.
3. Keep all names exactly as written; GitHub Pages is case-sensitive.
4. Go to Settings > Pages and select your main branch and /(root), then save if needed.
5. Wait a few minutes and open the published Pages link.
